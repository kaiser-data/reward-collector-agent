An agent that drafts the outreach and waits for my yes

It finds career switchers in my contacts, picks one fitting course for each, and writes up to five personal messages per run. I read, approve and send every one myself.

Needs your yes

Status 14 November 2026. All contacts and courses in this deck are mock data.

Finding the right people and writing to each one takes hours

  • Contacts come from partner lists, my own address book and Reddit. Each needs a different kind of message.
  • Follow-ups get forgotten, and a forgotten follow-up is a lost reward.
  • Writing to the wrong person, or twice in a week, costs trust that no reward repays.

The goal is a short read and a yes from me. The agent does the sorting and drafting.

From export to log, with one human gate

  1. ReadContacts, email history, courses, past results
  2. DraftUp to 5 texts, best leads first
  3. OutboxOne file per text, the exact words
  4. I decideYes, no or change, per text
  5. I sendFrom my private mailbox
  6. LogThe send is recorded, so the 14-day rule works
Optional: a one-way ping to Telegram that carries a count only, such as "5 drafts ready". No names, no texts, and nothing can come back in.

What it cannot do is as important as what it does

  • It never sends, posts or books. Each text is a file in the outbox until I say yes to those exact words.
  • It never pays, signs or deletes.
  • It reads only its own folder. No inbox access, no logins.
  • Memory stays mine. A file it reads cannot teach it. Only a line I type, or a lesson I approve.
  • A chat bot with full tool access was reviewed and left out. A message could steer it, and it would carry contact data through outside services.
